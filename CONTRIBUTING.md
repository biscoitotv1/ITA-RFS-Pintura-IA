# Contribuindo para o ITA-RFS-Pintura-IA

Obrigado por contribuir com este projeto.

## Como propor mudanças

1. Crie uma branch com uma descrição objetiva da alteração.
2. Faça mudanças pequenas e focadas.
3. Revise o conteúdo alterado antes de enviar.
4. Abra um pull request com contexto claro sobre o objetivo da mudança.

## Boas práticas

- Prefira alterações mínimas e específicas.
- Não misture correções não relacionadas na mesma entrega.
- Atualize a documentação quando a mudança afetar o uso ou a manutenção do repositório.

## Revisão

Ao abrir uma contribuição, descreva:

- o problema resolvido;
- o que foi alterado;
- como a mudança foi validada.

## Comunicação

Ao interagir neste repositório, siga as orientações descritas em `/CODE_OF_CONDUCT.md`.
